# 📚 Digital Library (Bibliotecă Digitală)

A simple and interactive web application built with **HTML5**, **CSS3**, and **Vanilla JavaScript**, designed to search for books in a local database using a unique book code.

## 🚀 Features

- **Dynamic Book Search:** Users can type a specific book code into the input field.
- **Array Data Handling:** Searches through a structured JavaScript array of book objects containing titles, authors, and publication years.
- **DOM Manipulation:** Dynamically creates and appends HTML elements (`<p>`) to display book details or error messages directly onto the page.
- **Modern Styling:** Clean, centered layout styled with CSS Flexbox and gradient backgrounds.

## 🛠️ Built With

- `HTML5` – Page structure and input field.
- `CSS3` – Styling, layout alignment with Flexbox (`display: flex`, `flex-direction: column`), and responsive inputs.
- `JavaScript (Vanilla)` – Event listeners (`change`), array iteration (`for` loop), conditional logic, and dynamic DOM manipulation.
